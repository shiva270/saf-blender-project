## Penggunaan

Sebelum setiap batch operasi Blender, baca `AGENTS.md`, `blender-director/SKILL.md`, skill spesialis yang sesuai, dan referensi yang diperlukan. Gunakan `realistic-style` untuk proyek SAF dan `qa-review` untuk memverifikasi hasil. Instruksi terbaru pengguna mengungguli arahan generik upstream.

Instalasi di tingkat proyek mengikuti format skill Codex `.agents/skills/<nama>/SKILL.md`. Jika katalog skill sesi belum memuatnya, file tetap dapat dibaca langsung; buka ulang sesi proyek untuk pemindaian ulang. Koneksi Blender MCP harus tersedia terpisah sebelum eksekusi scene.

Seluruh paket disimpan agar referensi lengkap tersedia secara lokal, tetapi penerapan skill dipilih berdasarkan tugas. Instalasi tidak mengubah status audit atau menyatakan scene SAF selesai.

## Pembaruan

Versi ini dipatok pada commit di atas. Untuk memperbarui, tinjau perubahan upstream, perbarui salinan skill dan referensi beserta commit sumber, lalu verifikasi jumlah serta isi file. Tidak ada auto-update yang diaktifkan.
